# 内部资料检索规则（演示版）

本资料为虚构演示数据，不对应真实企业，仅用于 AI Agent / RAGFlow 技术演示与检索测试，不构成医疗建议。

## 资料范围

本知识库仅包含六个演示产品：立普妥、拜阿司匹灵、波立维、可定、倍他乐克、益适纯，以及其虚构内部编号、分类、版本、状态和培训业务流程。

## 回答规则

只使用匹配到目标产品的段落。名称与内部编号必须准确对应。说明所用资料标题和版本。若没有目标产品或某字段，明确回答“内部资料未提供相关信息”，不要用其他产品替代，不要用模型常识或互联网知识补造。

## 数据源边界

内部资料不是实时库存。库存批次和效期来自MySQL；公开企业信息来自外部搜索，并与内部模拟资料分开。不将旧电商或金融资料引入医疗产品回答。
