# 医研智析模拟企业业务规则

仅供产品演示。以下均为虚构企业业务规则，不是药品临床资料或真实企业制度。

## 产品范围

演示沿用教学MySQL数据的generic_name、brand_name、drug_id。示例名称：阿托伐他汀钙片（立普妥）。名称仅用于匹配教学记录，不表达适应症、禁忌或用药建议。

## 库存分析

先核对真实表结构，以drug_id关联drugs与inventory；按批次或产品汇总quantity_on_hand，并注明查询条件与快照口径。不同仓库应分别展示，再汇总；不能把不同药品库存解释为可替代供应量。

## 销售分析

明确起止日期和region口径，分别汇总quantity_sold及total_amount。单价与金额不一致时标注待核对，不自动改库。没有进货流水时，不根据销售推断当前库存变化。

## 报告交付

报告注明模拟数据、数据范围、SQL筛选条件与限制。只在真实生成文件并由文件接口列出后显示可下载。附件上传不代表已导入知识库。
